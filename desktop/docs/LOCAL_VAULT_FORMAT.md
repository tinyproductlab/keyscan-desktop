# 本地加密保险箱格式

本格式只用于Windows/macOS本地运行数据，不作为Android数据库复制格式。跨平台迁移和同步仍使用版本化KeyScan安全备份。

## 外层容器

```text
KSV1DB1\0       8字节magic
iv              12字节随机IV
ciphertext      AES-256-GCM密文，末尾包含16字节认证标签
```

AES密钥是Android兼容的随机32字节`databaseKey`经标准Base64解码后的原始字节。每次写入重新生成IV，整个正文经过GCM完整性认证，文件通过同目录临时文件原子替换。

## 正文版本

- 版本1：密码记录。
- 版本2：密码记录和TOTP记录。
- 版本3：增加安全保险箱项目和附件元数据。
- 版本4：密码记录补齐Android的分组、OTP关联、应用包名、账号、备注及时间字段。

读取器继续接受版本1，下一次写入时升级为版本2。所有字符串均使用4字节大端长度加UTF-8字节，数量和字段长度在解析前验证。

## 安全边界

- 磁盘中不保存PIN、数据加密密钥或明文数据库密钥。
- 错误密钥、认证标签篡改、magic错误和截断文件均必须拒绝。
- 浏览器扩展不得直接读取本文件，只能通过已解锁桌面进程的Native Messaging接口请求最小数据。

## 附件容器

附件内容独立保存为`KSATT1\0\0 + IV12 + AES-256-GCM密文及标签`，密钥仍为当前保险箱数据库密钥。导入时流式加密并记录明文SHA-256；导出时先验证GCM和SHA-256，再原子写入用户选择的位置。附件路径只能位于KeyScan管理目录，拒绝绝对路径和目录穿越。
