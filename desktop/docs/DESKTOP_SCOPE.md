# KeyScan Desktop 功能范围

## 保留

- 首页
- 密码账本
- TOTP
- 安全保险箱及附件
- 随机密码
- 安全状态
- 安全备份：本地备份、双 WebDAV、历史、恢复、完整性验证
- 导入和导出
- 回收站
- 历史记录
- 仅查看与编辑模式
- 自动锁定和剪贴板定时清理
- Windows Hello / Touch ID
- 深色、浅色、跟随系统
- 全部现有语言
- 设置中的帮助、关于、用户协议和隐私政策

## 不移植或暂缓

- KeyScan Pro、购买、恢复购买及试用
- 手机悬浮窗
- 手机相机扫码和 OCR
- 相册二维码识别
- Android 自动填充服务
- 手机间临时局域网分享
- 二维码外观编辑和复杂分享中心
- 手机专用手势与卡片堆叠

## UI

- 左侧桌面导航，中间工作区。
- 密码账本和安全保险箱采用列表/详情分栏。
- 延续 Android 的渐变 KeyScan、盾牌、树叶和“安全 自由”品牌设计。
- 密码账本蓝色、TOTP 紫色、安全保险箱青绿色、随机密码橙色、安全备份蓝紫色。
- “语言”和“关于”放在设置中。
