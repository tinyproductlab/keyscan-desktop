# Windows 卸载前安全检查设计

## 目标

KeyScan 卸载时不应直接丢失用户数据。卸载程序删除应用文件前，必须让用户有机会完成安全备份或导出，并明确说明默认保留本地保险箱数据。

## 用户流程

1. 用户从 Windows 设置、开始菜单或安装器选择卸载。
2. 安装器启动 KeyScan 的卸载前检查入口；如果主程序已运行，复用其受保护会话。
3. KeyScan 要求 PIN；已配置 Windows Hello 时可选择 Windows Hello。安装器本身永不读取 PIN、数据保护密钥或数据库密钥。
4. 验证成功后显示三个操作：
   - **创建加密安全备份**：使用现有 V5/V6 兼容安全备份流程，可选本地或已配置 WebDAV；显示完成时间和保存位置。
   - **导出数据**：进入明确的导出确认流程，提示导出文件可能为明文或兼容格式，需自行保护。
   - **仅卸载并保留本地数据**：不创建新副本，明确提示下次安装需使用原 PIN 和数据保护密钥。
5. 完成备份／导出，或明确选择保留本地数据后，KeyScan 生成仅当前卸载会话可用、短时有效的一次性确认结果。
6. 安装器验证该结果后继续卸载；验证失败、超时、锁屏或取消均停止卸载。

## 数据删除规则

- 默认卸载只删除程序、开始菜单项、安装器注册信息及 Native Messaging 注册信息。
- 默认不删除保险箱、附件、DPAPI/Keychain 本地凭据、备份历史或用户导出的文件。
- “删除所有本地数据”必须是独立的后续操作：再次 PIN/Windows Hello 验证、明确列出路径、输入确认文字，并保留取消入口。
- 任何 WebDAV/NAS 上的备份均不由卸载程序删除。

## 安全边界

- PIN、数据保护密钥、数据库密钥、备份根密钥与明文导出内容不得传给 MSI/EXE 安装器或写入日志、命令行、注册表。
- 安装器与应用之间只能使用当前用户、一次性、短时有效的受认证 IPC；必须校验调用用户与卸载会话。
- 静默卸载没有交互能力：默认保留所有用户数据，并在安装器日志中只记录“用户数据保留”，不记录敏感内容。
- 应用未安装完整、IPC 不可用或身份验证失败时，安装器必须回退为“仅删除程序文件、保留数据”，不得绕过验证删除数据。

## 实现和验证清单

- [ ] 应用内实现卸载前安全检查页面与 PIN/Windows Hello 二次验证。
- [ ] 接入本地安全备份、WebDAV 安全备份与受确认的数据导出。
- [ ] 实现当前用户的一次性卸载确认 IPC，锁屏、超时和取消时失效。
- [ ] 为 EXE/MSI 添加启动检查与默认保留数据的卸载行为。
- [ ] 在干净 Windows 用户环境验证：备份、导出、保留数据、取消、PIN 错误、Hello 取消、静默卸载、升级与重新安装恢复。
